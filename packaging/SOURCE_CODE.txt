Inventory Manager mini - 対応ソースの取得案内
==============================================

各バイナリの対応ソースは、そのバイナリと同じ GitHub Release から追加費用なしで取得できる
ように提供します。対象タグ・コミット SHA・アプリ版・依存の実版とソース成果物の対応は、
同じ Release に添付する構成一覧 (-manifest.json) で確認してください。

Release の `<アプリ版数>[-rc<N>]-sources.zip` には、対象コミットのアプリソース、SQL、必要な
資産、LICENSE、pyproject.toml、uv.lock、PyInstaller spec、Inno Setup スクリプト、ビルド用
スクリプト、およびソースから変更・ビルド・インストールする手順を含めます。実際のバイナリに
含まれる GPL 等の対象依存については、同じ Release に版を対応させた必要なソースとビルド設定・
変更内容を添付します。上流 URL、wheel、GitHub 自動生成 ZIP だけでは対応ソースの代わりになりません。

System Libraries 等を対応ソースから除外する場合は、適用条件と除外理由を構成一覧に記録します。
Release の添付ファイルと SHA256 は、インストーラー、アプリソース、依存ソース、構成一覧の対応を
確認するために使ってください。バイナリを提供している間は、対応するソースも取得できる状態を
維持します。

このリポジトリには利用者のデータベース、バックアップ、ログ、個人情報は含めません。

注意: この案内ファイルは配布手順の定義です。依存ソースの収集、版対応、Release への添付が
完了するまでは、特定ビルドの対応ソースを提供済みとみなせません。
