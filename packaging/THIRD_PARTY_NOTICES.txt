Inventory Manager mini - 第三者ソフトウェア通知
==================================================

この一覧は 2026-10-13 時点の uv.lock、ローカル Python 3.13.12 環境、および Phase 2 の
試験 onedir から確認できた情報です。Phase 2 の onedir は Phase 8 の spec で作り直した
最終配布物ではないため、配布前に最終バンドルを再度棚卸ししてください。

Phase 2 試験 onedir の観察結果:
- `dist/inventory-manager-mini/` の `_internal/` に 222 ファイルがありました。
- Qt 6.11.2 の実行環境にある QtCharts・QtPrintSupport と `Qt6Charts.dll`・`Qt6Core.dll`・
	`Qt6PrintSupport.dll` のほか、QtGui/Network/OpenGL/Pdf/Qml/Quick/Svg/Widgets 系の DLL、
	translations と plugins が含まれています。plugins には platforms (`qwindows.dll` など)、
	imageformats、styles、tls 等がありました。全ファイルの版・由来・ライセンスは未照合です。
- Python runtime の `python313.dll`、`python3.dll`、`sqlite3.dll`、`libcrypto-3-x64.dll`、
	`libssl-3-x64.dll`、`libffi-8.dll`、Microsoft runtime DLL 等が含まれていました。
- ファイル名に license/copying/notice を含む通知ファイルはなく、同梱要件を満たしていません。
- 同梱されたアプリ metadata は 0.1.0 でしたが、ライセンス・著者 metadata はありませんでした。
- 旧 spec は Qt Charts/PrintSupport と個別画面を hidden import し、UPX を有効にしています。
	Phase 8 spec は全アプリサブモジュールを収集するため、最終バンドルの構成は一致しません。
