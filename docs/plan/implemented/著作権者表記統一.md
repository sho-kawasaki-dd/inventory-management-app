# 著作権者表記の統一

**ステータス: 完了（凍結）**

## 目的

アプリの著作権者表記を `Kawasaki Sho` に統一し、ライセンス通知、アプリ表示、インストーラー、パッケージメタデータ、現行仕様の記載を一致させる。

## 要件

- 自作コードおよび配布物の著作権表示を `Kawasaki Sho` にする。
- 「バージョン情報」とインストーラーの著作権表示にも同じ名前を表示する。
- パッケージの作者メタデータを `Kawasaki Sho` にする。
- `IKinoCore` はインストーラーの発行元として維持し、役割を著作権者と混同しない。
- 現行仕様の正本を更新する。完了済みの Phase 8 実装計画書は変更しない。
