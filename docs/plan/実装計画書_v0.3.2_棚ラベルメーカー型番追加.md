# v0.3.2 実装計画書(棚ラベル印刷へのメーカー型番追加)

- 作成日: 2026-10-20
- ステータス: 実装前
- 作業ブランチ: `feature/v0.3.2-plan`(計画書作成)→ `feature/v0.3.2-label-model-number`(実装・正本統合)
- 基盤とする文書: [ローカル在庫管理アプリ開発計画書](ローカル在庫管理アプリ開発計画書.md)(3.1・3.2・5.1・6.3・6.4・8・9.1 章)

---

## 1. 目的

- 棚ラベル(`エーワン 72212`)の印字項目に「メーカー型番(`manufacturer_part_number`)」を追加し、棚や保管容器に貼付したラベルからメーカー型番を直接確認できるようにする。
- 棚ラベル印刷ダイアログ(`LabelPrintDialog`)の品目表にも「メーカー型番」列を追加し、印刷枚数を指定する際に対象品目のメーカー型番を確認できるようにする。
- 上記の改修に伴い、アプリの版数を `0.3.1` から `0.3.2` へ引き上げ、確定した仕様を開発計画書(正本)へ統合する。

## 2. 要件

### 2.1 満たすべき仕様

- 開発計画書 3.1(層構成と依存方向)、3.2(モジュール構成)、5.1(品目)、6.3(画面詳細)、6.4(表示要件)、8 章(テスト方針)、9.1(印刷の基本設計)に従う。

| 項目 | 状況 |
| --- | --- |
| ラベルの描画 | `ui/printing/label_renderer.py` の `_LABEL_TEXT_ROWS` は `((3.0, 11, True), (11.0, 14, True), (20.0, 10, False), (29.0, 9, False))` の 4 行定義。`_item_label_text(item)` は `(item.name, item.code, item.location_name or "", note)` の 4 要素タプルを返す。開発計画書 9.1 は「印字項目: 品名・管理番号・保管場所・備考(メーカー型番・用途は印字しない)」と明記している |

| 棚ラベル印刷ダイアログ | `ui/printing/label_print_dialog.py` の `LabelPrintDialog.item_table` は 3 列(`["管理番号", "品名", "枚数"]`)。列 0 は `ResizeToContents`、列 1 は `Stretch`、列 2 は `Fixed`(幅 90px)で枚数指定用の `QSpinBox` を配置している |
| 品目データ | `ItemRow` はすでに `manufacturer_part_number: str \| None` を保持しており、Service・Repository・モデル層の変更は不要 |
| 在庫表印刷 | `INVENTORY_SHEET_COLUMNS` にはすでに「メーカー型番」列が含まれており、変更不要 |
| 既存テストの前提 | `tests/test_label_print.py` の `_item_row()` は `manufacturer_part_number=None` を既定値とし、描画テスト(`test_render_labels_uses_device_metrics_and_preserves_selected_slot`・`test_render_labels_new_page_failure_stops_before_later_page`・`test_render_labels_elides_long_text_within_inner_width_at_device_dpi`・`test_render_labels_range_keeps_original_slots_without_reapplying_first_page_checks`)は 1 ラベルあたりの描画数やフォントサイズ配列 `[11, 14, 10, 9]` を 4 行前提で検証している |
| 版数定義 | `pyproject.toml` の `version = "0.3.1"` を正本とし、`__init__.py` は `importlib.metadata.version` で動的に取得する。`uv.lock` と `README.md`(インストーラー・ビルド例)に `0.3.1` が記載されている。DB スキーマの変更はなく、`SCHEMA_VERSION = 5` は維持する |

### 2.3 決定事項

| 項目 | 決定 |
| --- | --- |
| ラベルの印字項目と順序 | 上から順に **品名・メーカー型番・管理番号・保管場所・備考** の 5 行固定とする(用途は印字しない) |
| 各行のフォントと縦位置 | ラベル内側余白は 3.0mm を維持し、`_LABEL_TEXT_ROWS` を次の 5 行定義とする。①品名(太字 11pt、`top_offset_mm = 3.0`)、②メーカー型番(標準 10pt、`top_offset_mm = 9.5`)、③管理番号(太字 14pt、`top_offset_mm = 16.0`)、④保管場所(標準 10pt、`top_offset_mm = 24.5`)、⑤備考(標準 9pt、`top_offset_mm = 31.5`) |
| メーカー型番の印字形式 | 他の項目と同様に見出し(「型番:」等の接頭辞)は付けず値のみを印字する。未登録(`None` または空文字)の場合も行を詰めず、各行の縦位置を固定する。改行が含まれる場合の空白置換は備考のみとし、各行は 1 行で `QFontMetrics.elidedText(ElideRight)` により描画幅内へ切り捨てる |
| 棚ラベル印刷ダイアログの列構成 | `LabelPrintDialog` の `item_table` を 4 列(`["管理番号", "品名", "メーカー型番", "枚数"]`)に変更する。列のリサイズモードは 列 0(管理番号): `ResizeToContents`、列 1(品名): `Stretch`、列 2(メーカー型番): `Stretch`、列 3(枚数): `Fixed`(幅 90px)とする。`item.manufacturer_part_number` が `None` のときは空文字 `""` を表示し、編集不可フラグを設定する |
| 版数 | アプリ版数を `0.3.2` に引き上げる(`pyproject.toml`・`uv.lock`・`README.md`)。`SCHEMA_VERSION = 5` は維持する。`README.md` の「v0.3.0 の DB・バックアップは v0.2.0 以前のアプリでは開けません」は、スキーマ版が変わらないため据え置く |
